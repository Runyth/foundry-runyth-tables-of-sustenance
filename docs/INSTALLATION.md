# runyth-tables-of-sustenance-1.1.1

## Installation

1. Extract the installable ZIP into `Data/modules` so `Data/modules/runyth-tables-of-sustenance/module.json` exists.
2. Restart Foundry VTT.
3. Enable **Runyth Tables of Sustenance** in the world.
4. Open the dashboard from the Item sidebar or Configure Settings.
5. For mechanical inventory/effects, also install a complementary adapter for the active game system.

### D&D 5e 2024

Install and enable `runyth-tables-of-sustenance-dnd5e-2024` after the core. The companion requires core 1.1.0 or newer.

When upgrading from core 1.0.1, install the new core and the D&D companion before updating/importing managed food Items in an existing D&D world.
