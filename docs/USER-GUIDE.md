# runyth-tables-of-sustenance-1.1.1

## User Guide

The Food Browser, menus, recipes, lore, filters, images and Tier information are system-neutral. Dragging a food to an Actor or importing food Items requires a compatible system adapter because each game system defines Item data differently.

Tier 1 remains narrative sustenance. Tiers 2–4 and Tier S carry neutral effect intents. The core decides stacking, cooldown, duplicate and permanent-benefit policy; the adapter converts those intents into the current game's mechanics.

If no adapter is active, Diagnostics reports that state. The module does not create guessed or malformed Items.

Image overrides, Import/Export, Content Manager, Diagnostics and menu generation remain available regardless of system adapter.
