# runyth-tables-of-sustenance-1.1.1

## Diagnostics

The Diagnostics dashboard reports the active module, Foundry and system versions, packaged plus registered food totals, Tier S count, managed compendium counts, duplicate stable source IDs, image-override findings, and complementary providers. GM-triggered runs retain a compact five-entry summary history in world settings. Reports can be exported as JSON.
