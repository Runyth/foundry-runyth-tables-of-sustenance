# runyth-tables-of-sustenance-1.0.1
## UX and Generic-Feature Audit

- Removed fixed compact dashboard assumptions that caused localized text overflow.
- Replaced rigid two-column dashboard layout with responsive auto-fit cards and equal implicit rows.
- Added safe text wrapping, `min-width: 0`, content-sized buttons, minimum touch/control height, visible focus state, and narrow breakpoints.
- Split browser filters/results into independent Handlebars parts so typing does not replace the active input.
- Reworked food cards around responsive image/content columns and stable action grids.
- Added direct GM FilePicker image selection/reset and imported-Item synchronization.
- Added Import / Export, Diagnostics, and client window-geometry maintenance surfaces.
- Added exact-provenance destructive/transfer filtering.
- Added complementary provider/food API and extension diagnostics.
