# runyth-tables-of-sustenance-1.1.1

## Cookbook and Recipe System

The module includes 190 JournalEntry recipe sources for all mechanically exceptional foods and a representative range of ordinary regional dishes.

Each recipe distinguishes:

- the food’s existence from possession of its recipe;
- known recipes stored on an actor;
- required ingredients and tools;
- preparation difficulty and time;
- restricted authorisation where applicable;
- failure, partial success, batch yield, and spoiled outcomes;
- GM-only or unidentified recipes;
- counterfeit legendary recipe hooks.

The public recipe service supports learning, forgetting, availability checks, ingredient/tool/authorisation checks, and JSON import/export. It deliberately does not replace a full crafting-economy module. Ingredient inventory consumption and downtime scheduling can be delegated through the API adapter layer.

Recipe source flags use the food’s stable source identifier, so renaming either document does not break the relationship.
